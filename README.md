# AI Movie Trailer Generator

## Overview

This project generates a movie trailer using Artificial Intelligence.

The user enters a movie title and genre.

The application then:

* Generates a movie story using Google Gemini
* Creates a cinematic trailer script
* Extracts narration from the trailer
* Converts narration into voice using Edge-TTS
* Generates image prompts
* Combines images and voice into a movie trailer using MoviePy

## Technologies Used

* Python
* Google Gemini API
* Edge-TTS
* MoviePy
* Google AI Studio

## Workflow

Movie Title + Genre

↓

Movie Story

↓

Trailer Script

↓

Narration

↓

Voice Generation

↓

Image Prompt Generation

↓

Movie Trailer

## How to Run

1. Install Python packages.

```
pip install google-genai edge-tts moviepy pillow
```

2. Add your Gemini API Key.

3. Run the notebook or Python file.
